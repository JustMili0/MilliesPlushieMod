# Why?
Why not? I felt like making a mod for my dev team as a "thank you" for the great work they've done,<br>
a mod to make something special for people who's content I enjoy watching,<br>
and a mod to bring my favorite game characters into Minecraft.

### How long will this be kept updated?
I generally keep all mods I've made and maintain fully up-to-date,
e.g. [Always Shield](https://modrinth.com/mod/always-shield) and [Shulkers In Bundles](https://modrinth.com/mod/shulkers-in-bundles).<br>
So this mod as all other of mine will be kept updated probably as long as I live.

### Support for more?
No. I'm not gonna port this mod over to NeoForge, Forge or Quilt and I will not port it down to lower versions like 1.20.1, 1.21.1 etc.

### Can you add [insert creator or game character]?
Ofcourse! You can submit a request to add a content creator or a game character
on the mod's [issues page](https://github.com/JustMili0/MilliesPlushieMod/issues), and I'll add them in!
